# Feature Specification: PWA Install Banner & iOS A2HS Tooltip

**Feature Branch**: `025-pwa-install-banner`

**Created**: 2026-06-17

**Status**: Draft

**Input**: User description: "스마트 단말기(iOS, Android)의 beforeinstallprompt 제어 배너 설계 및 사파리 수동 툴팁 A2HS 레이아웃 가이드 구현."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Android 및 지원 브라우저용 커스텀 설치 배너 제어 (Priority: P1)

설치가 가능한 Android 단말 및 크롬 등의 브라우저로 접속한 사용자는 브라우저의 기본 설치 창이 멋대로 뜨는 대신, 우리 서비스의 톤앤매너에 맞게 설계된 커스텀 설치 안내 배너를 통해 세련되게 앱 설치를 시작할 수 있어야 합니다.

**Why this priority**: 기본 설치 팝업은 사용자 흐름을 방해하므로, 적절한 시점에 서비스 고유의 브랜딩이 적용된 배너를 띄워 설치 전환율을 높이고 사용자 경험을 향상하기 위함입니다.

**Independent Test**: Android Chrome 브라우저로 접속 시 브라우저 기본 설치 팝업이 차단되고, 하단에 커스텀 설치 안내 배너가 표시되는지 확인합니다. "설치"를 누르면 브라우저 공식 설치 확인 창이 팝업되고, "닫기"를 누르면 배너가 사라지는지 테스트할 수 있습니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 PWA 설치가 가능한 Android Chrome 브라우저로 가계부 웹 앱에 접속했을 때,  
   **When** 페이지가 로드되고 설치 조건이 충족되면 (브라우저 기본 팝업은 억제됨),  
   **Then** 화면에 커스텀 PWA 설치 유도 배너가 표시된다.
2. **Given** 설치 유도 배너가 노출된 상태에서,  
   **When** 사용자가 "설치하기" 버튼을 클릭하면,  
   **Then** 브라우저가 지원하는 공식 앱 설치 동의 팝업창이 나타난다.
3. **Given** 공식 앱 설치 동의 팝업창이 뜬 상태에서,  
   **When** 사용자가 설치를 최종 수락하면,  
   **Then** 설치 프롬프트가 닫히며 화면의 설치 배너는 즉시 사라지고 가계부를 독립된 앱 인터페이스로 계속해서 사용한다.
4. **Given** 설치 유도 배너가 노출된 상태에서,  
   **When** 사용자가 "닫기" 버튼을 클릭하면,  
   **Then** 배너가 즉시 사라지며 설정된 기간 동안 다시 노출되지 않는다.

### User Story 2 - iOS Safari 전용 홈 화면 추가(A2HS) 수동 안내 툴팁 (Priority: P1)

`beforeinstallprompt` API가 지원되지 않는 iOS Safari 브라우저 환경의 사용자가 진입했을 때, 브라우저 하단 영역의 공유 버튼과 "홈 화면에 추가" 메뉴를 순차적으로 클릭하도록 안내하는 수동 비주얼 가이드 툴팁이 하단에 예쁘게 표시되어야 합니다.

**Why this priority**: iOS Safari 환경은 웹 PWA의 주 사용자층 중 큰 비중을 차지하지만 자동 설치 트리거가 불가능하므로, 시각적으로 명확한 툴팁 가이드라인을 제공하지 않으면 설치 방법을 인지하기 매우 어렵기 때문입니다.

**Independent Test**: iOS 기기의 Safari 브라우저로 접속했을 때, 하단 공유 버튼 방향을 가리키는 말풍선 모양의 툴팁 가이드(공유 아이콘 모양 및 문구 포함)가 표시되는지 확인합니다. 닫기 버튼으로 가이드를 숨길 수 있으며, 이미 설치된 상태(Standalone)에서는 가이드가 뜨지 않는지 검증합니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 iOS Safari 브라우저를 통해 가계부 웹 앱에 비설치 상태로 접속했을 때,  
   **When** 앱 화면이 정상적으로 렌더링되면,  
   **Then** 화면 하단 중앙(또는 공유 버튼 근처)에 Safari 공식 공유 아이콘 디자인과 안내 텍스트("공유 버튼을 누르고 '홈 화면에 추가'를 클릭하세요")가 포함된 툴팁 가이드 배너가 노출된다.
2. **Given** iOS Safari 안내 툴팁이 표시된 상태에서,  
   **When** 사용자가 툴팁 내부의 "닫기" 버튼을 클릭하면,  
   **Then** 툴팁이 즉시 사라지고 설정된 기간 동안 다시 노출되지 않는다.

### User Story 3 - 이미 설치 완료된 앱 진입 시 배너 및 가이드 제외 (Priority: P2)

이미 스마트 단말기 홈 화면에 가계부 앱을 추가하여 독립 실행형 모드(Standalone)로 앱을 구동한 사용자에게는 어떠한 설치 유도 배너나 툴팁 가이드도 노출되지 않고 깨끗한 화면을 제공해야 합니다.

**Why this priority**: 이미 설치를 완료해 독립 모드로 앱을 유용하게 쓰고 있는 사용자에게 불필요한 설치 가이드를 계속 보여주는 것은 혼란을 야기하고 불필요한 화면 공간을 차지하기 때문입니다.

**Independent Test**: 홈 화면에 추가된 PWA 아이콘을 눌러 웹 앱을 독립 모드(Standalone)로 실행했을 때, 화면 내에 Android 설치 배너와 iOS 수동 설치 가이드 툴팁이 모두 완벽하게 숨겨져 있는지 검증합니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 이미 가계부 앱을 설치한 후,  
   **When** 모바일 홈 화면의 바로가기 아이콘을 통해 독립 실행형(Standalone) 모드로 진입하면,  
   **Then** Android 설치 유도 배너 및 iOS Safari 안내 툴팁이 모두 비활성화되어 화면에 노출되지 않는다.

---

### Edge Cases

- **네트워크 오프라인 상태**: 기기가 오프라인 상태일 때 브라우저의 설치 가용성이 제한될 수 있으므로, 오프라인 상태이거나 서비스 워커가 정상적으로 활성화되지 않은 시점에는 무리하게 배너를 띄우지 않고 대기해야 합니다.
- **Safari 브라우저가 아닌 iOS 인앱 브라우저 및 타 브라우저 진입**: iOS 크롬이나 카카오톡 인앱 브라우저 등은 자체적으로 "홈 화면에 추가" 동작을 원활하게 제공하지 못하므로, 설치 지원이 불가능한 환경으로 판별하여 어떠한 설치 유도 안내 배너나 툴팁도 노출하지 않고 완전히 생략 처리합니다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 사용자 단말 및 브라우저 환경을 자동으로 감지하고, 이미 독립 모드(`standalone`)로 실행 중이거나 PWA가 지원되지 않는 비-모바일(데스크톱 제외) 환경인 경우 배너를 모두 숨겨야 합니다.
- **FR-002**: Android 및 `beforeinstallprompt`를 지원하는 브라우저 환경에서는 기본 설치 대화를 취소(Prevent Default)하고, 커스텀 디자인된 가로형/카드형 하단 배너를 노출해야 합니다.
- **FR-003**: 사용자가 Android 커스텀 배너에서 "설치" 버튼을 클릭하면, 억제해 두었던 설치 프롬프트 이벤트를 활성화하여 브라우저 순정 설치 창을 띄워야 합니다.
- **FR-004**: iOS Safari 브라우저 환경을 감지한 경우, 화면 하단 탭 바 혹은 브라우저 메뉴 바 방향(가운데 아래 방향)으로 뾰족한 툴팁 꼬리를 가진 수동 가이드 툴팁을 표시해야 합니다.
- **FR-005**: iOS Safari 수동 가이드 툴팁에는 Apple 표준 공유 아이콘(네모 안에서 위로 뻗어나가는 화살표) 이미지와 '홈 화면에 추가' 텍스트를 시각화하여 사용자가 쉽게 찾을 수 있도록 레이아웃 가이드를 제공해야 합니다.
- **FR-006**: 사용자가 설치 배너나 수동 가이드 툴팁을 명시적으로 닫았을 때(닫기 버튼 클릭), 로컬 스토리지 등에 차단 시각 상태 값을 기록하여 최소 7일(일주일) 동안은 해당 기기에서 배너가 재노출되지 않도록 제어해야 합니다. (FR-007 조항 흡수 및 단일화)
- **FR-007**: [삭제 - FR-006에 병합됨]
- **FR-008**: iOS 환경에서 Apple 공식 Safari 브라우저가 아닌 타사 브라우저(Chrome, Firefox) 또는 인앱 브라우저(카카오톡, 인스타그램 등)를 통해 진입한 경우에는 설치 지원이 불가하므로 설치 배너 및 수동 툴팁 가이드라인 안내를 완전히 제외합니다.
- **FR-009**: 설치 유도 배너 및 툴팁은 사용자가 웹 페이지 진입 및 초기 로드가 완료된 후 3초의 지연 시간을 두고 서서히 나타나도록 애니메이션 노출 제어를 수행해야 합니다.

### Key Entities *(include if feature involves data)*

- **InstallBannerState (로컬 브라우저 상태 관리용 엔티티)**:
  - `dismissedAt` (DateTime): 사용자가 배너나 툴팁을 마지막으로 닫은 시각. 이 시간과 현재 시간을 비교하여 쿨다운 차단 기간이 지났는지 판단합니다.
  - `platform` (String): 감지된 사용자 플랫폼 정보 (`android`, `ios_safari`, `ios_other`, `unknown`).
  - `standalone` (Boolean): 현재 앱이 Standalone 모드로 실행 중인지 여부.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 모바일 단말기로 최초 진입하여 미설치 상태인 사용자에게 알맞은 배너(Android 커스텀 배너 혹은 iOS Safari 수동 가이드 툴팁)가 노출되는 비율이 100%여야 합니다.
- **SC-002**: 설치 배너 또는 툴팁에서 "닫기" 버튼을 누른 사용자가 쿨다운 차단 기간 이내에 다시 앱을 새로고침하여 진입했을 때, 배너가 노출되지 않는 일관성이 100% 보장되어야 합니다.
- **SC-003**: 사용자가 Android 커스텀 배너 내의 "설치" 버튼을 누를 시 브라우저 공식 설치 팝업이 0.5초 이내에 사용자 화면에 즉각 트리거되어야 합니다.
- **SC-004**: 독립 실행 모드(`standalone`)로 앱을 구동했을 때, 어떤 단말 환경에서도 설치 안내 UI가 노출되지 않아야 합니다.

## Assumptions

- 사용자의 모바일 브라우저 환경에서 쿠키 및 LocalStorage 저장이 정상적으로 동작한다고 가정합니다. (차단 쿨다운 상태 기록용)
- PWA 매니페스트 및 서비스 워커는 기본적으로 프로젝트 루트 및 프론트엔드 빌드 상에 정상 배치 및 세팅되어 설치성(Installability) 조건을 충족하고 있다고 가정합니다.
- iOS 기기의 경우 브라우저 하단 탭 바가 켜져 있는 순정 Safari 환경을 기본 UI 레이아웃 타겟으로 설정합니다.
