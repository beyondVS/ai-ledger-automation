# Implementation Plan: Dashboard Ledger List and Detail Accordion Component

**Branch**: `011-dashboard-ledger-list` | **Date**: 2026-06-07 | **Spec**: [spec.md](file:///D:/Projects/Private/ai-ledger-automation/specs/011-dashboard-ledger-list/spec.md)

**Input**: Feature specification from `/specs/011-dashboard-ledger-list/spec.md`

## Summary

로그인 상태가 인증된 실제 사용자의 가계부 마스터 내역을 결제일 최신순으로 정렬하고 당월(현재 월) 지출 내역만 필터링하여 프론트엔드 대시보드 리스트에 렌더링합니다. 각 가계부 항목을 클릭 시, 1회 리스트 호출로 함께 수령한 상세 품목 데이터(`ledger_items` 기반의 `items` 배열)를 아코디언 컴포넌트를 활용해 300ms 이내의 모션으로 즉시 펼쳐 줍니다. 미완료("PENDING") 작업은 최상단에 Shimmer 로더 형태로 로딩 상태를 처리합니다.

## Technical Context

**Language/Version**: Python 3.11 (Backend Django/DRF) | JavaScript/Node.js (Frontend Vue 3/Vite)

**Primary Dependencies**: Django, djangorestframework, djangorestframework-simplejwt, Vue 3, Vite, Tailwind CSS, Axios

**Storage**: PostgreSQL v18+ (ACID 마스터 데이터 저장) | Redis (작업 상태 및 세션 토큰 제어)

**Testing**: pytest (테스트 러너) | Django TestCase & `setUpTestData(cls)` (백엔드 데이터베이스 격리 연동 테스트)

**Target Platform**: Web Browser / PWA Standalone (Mobile & Desktop)

**Project Type**: web-service & frontend (모노레포 통합 서비스)

**Performance Goals**: 대시보드 API 쿼리 응답 속도 100ms 이내 방어, 리스트 렌더링 체감 로드 1.5초 이하, 아코디언 컴포넌트 펼침 연산 지연 300ms 이하

**Constraints**:
- **인증 연동**: JWT Access Token 기반 로그인 상태 필수 연동 및 헤더(`Authorization: Bearer <token>`) 주입
- **커넥션 풀 제한**: `api_server` 컨테이너의 최대 데이터베이스 커넥션 풀 크기를 **5**개로 엄격 제한
- **데이터 격리**: `Ledger.objects.filter(user=request.user)` 격리 필터 상시 적용

**Scale/Scope**: 가계부 내역 100건 이상 누적 시에도 버벅임 없는 리스트 스크롤링 및 스무스한 CSS 트랜지션 처리
