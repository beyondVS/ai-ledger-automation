# Feature Specification: 가계부 UI 고도화 1단계 (소비 시각화 차트 및 예산 게이지)

**Feature Branch**: `020-visualize-spending`

**Created**: 2026-06-14

**Status**: Approved

**Input**: User description: "가계부 UI 고도화 1단계 (소비 시각화 차트 및 예산 게이지). 카테고리별 소비 분포 원형 차트 및 월별 지출 흐름 막대 차트 컴포넌트를 구현하고 월 예산 대비 남은 예산 게이지 바, 이번 달 지출 TOP 3 가맹점 요약 카드를 추가하여 직관적인 소비 대시보드 제공."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 소비 대시보드 진입 및 소비 시각화 차트 확인 (Priority: P1)

사용자는 가계부 대시보드 화면에 진입하여 직관적으로 구성된 소비 시각화 정보를 한눈에 확인합니다. 화면에는 이번 달 카테고리별 소비 분포를 보여주는 원형 차트와 최근 수개월간의 월별 지출 추이를 보여주는 막대 차트가 렌더링되어, 과거 지출 규모와 현재의 카테고리별 집중 소비처를 비교 분석할 수 있습니다.

**Why this priority**: 소비 상태를 시각적으로 빠르게 인지하여 합리적인 소비 결정을 내릴 수 있도록 돕는 본 대시보드 피처의 핵심 MVP 핵심 가치입니다.

**Independent Test**: 사용자가 가계부 메인 대시보드에 진입하였을 때, 당월 카테고리 분포 원형 차트와 월별 지출 추이 막대 차트가 정상적으로 노출되고, 마우스 오버 시 각 요소의 상세 금액 및 비율 데이터가 올바르게 표현되는지 검증합니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 이번 달에 식비(40만원), 교통비(10만원) 등 여러 카테고리로 가계부 데이터를 등록한 상태에서, **When** 대시보드 화면에 진입하면, **Then** 전체 지출 대비 각 카테고리의 비율(식비 80%, 교통비 20%)을 시각화한 원형 차트가 노출됩니다.
2. **Given** 가계부에 최근 수개월간의 월별 지출 내역이 존재하는 상태에서, **When** 대시보드 화면에 진입하면, **Then** 기본 3개월(사용자가 3개월, 6개월, 12개월 등 조회 개월 수를 UI에서 동적 선택 가능) 동안의 총지출 총액 추이가 막대 그래프로 렌더링되어 나타납니다.

---

### User Story 2 - 월 예산 대비 남은 예산 게이지 확인 및 예산 수정 (Priority: P2)

사용자는 설정한 월 예산 대비 현재까지 소비한 누적 지출액과 남은 예산 비율을 시각적인 게이지 바 형태로 확인합니다. 예산의 소진 정도에 따라 게이지 바의 색상이 가시적으로 변화(예: 안전/주의/경고)하여 충동적인 과소비를 예방하도록 돕고, 필요한 경우 대시보드 내에서 간편하게 예산을 수정할 수 있습니다.

**Why this priority**: 설정한 예산 목표 대비 현재 소비 속도를 직관적으로 확인하고 조절하게 함으로써 가계부 고유의 자금 통제 기능을 수행할 수 있도록 합니다.

**Independent Test**: 예산 소진 비율에 맞춰 게이지 바의 채움 그래픽과 색상(안전/주의/경고)이 설정된 임계치 규칙대로 변경 노출되는지 검증하고, 예산 수정 시 수치가 실시간으로 갱신되는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 이번 달 예산이 1,000,000원으로 설정되어 있고 당월 누적 지출액이 300,000원(소진율 30%)인 상태에서, **When** 대시보드를 로드하면, **Then** 게이지 바가 30% 영역만큼 채워지고 "남은 예산: 700,000원 (70%)" 정보가 안전 상태(예: 녹색 계열)로 표시됩니다.
2. **Given** 대시보드 내 예산 편집 UI가 제공되어 사용자가 직접 월 예산을 설정 및 변경할 수 있는 상태에서, **When** 사용자가 예산을 1,500,000원으로 조정하면, **Then** 백엔드 API를 호출하여 예산 데이터를 영속화하고, 대시보드를 새로고침하지 않아도 게이지 소진율(20%) 및 남은 예산(1,200,000원)이 즉시 동적으로 재계산되어 표시됩니다.

### User Story 3 - 이번 달 지출 TOP 3 가맹점 요약 확인 (Priority: P3)

사용자는 이번 달에 자신이 가장 많은 소비 활동을 한 주요 가맹점 상위 3곳과 해당 지출 수치를 요약 카드 형식으로 확인합니다. 이를 통해 어떤 구체적인 가맹점에서 과소비가 발생하고 있는지 빠르게 파악할 수 있습니다.

**Why this priority**: 대분류 카테고리 분석에서 한 단계 더 나아가 실질적으로 지출이 가장 빈번하거나 규모가 큰 상위 가맹점 정보를 직관적으로 요약 제공하여 실질적인 소비 개선을 유도합니다.

**Independent Test**: 가계부 지출 데이터에서 당월 지출 기준 상위 3개 가맹점의 정보가 순위에 맞춰 올바르게 추출 및 표시되는지 검증합니다.

**Acceptance Scenarios**:

1. **Given** 당월에 가맹점 A(30만원, 3회), 가맹점 B(20만원, 1회), 가맹점 C(15만원, 5회), 가맹점 D(5만원, 2회) 지출 내역이 등록된 상태에서, **When** 대시보드를 조회하면, **Then** 당월 지출 총액 합산액이 가장 큰 가맹점 TOP 3 기준(가맹점 A: 30만원, 가맹점 B: 20만원, 가맹점 C: 15만원)에 따라 정렬된 상위 3개 가맹점 명칭과 요약 금액이 요약 카드 형태로 표시됩니다.

---

### Edge Cases

- **당월 결제 및 지출 내역이 전혀 없는 경우**:
  - 차트 및 게이지 영역이 빈 레이아웃으로 무너지거나 에러가 발생하지 않아야 하며, "이번 달 지출 내역이 없습니다."와 같은 직관적인 안내 메시지와 함께 0원 지출 상태 및 보존된 예산 수치를 정상 표시해야 합니다.
- **예산 미설정 혹은 예산이 0원으로 등록된 경우**:
  - 남은 예산 게이지 계산 시 0으로 나누기(Divide by Zero) 에러를 방지해야 하며, 게이지 바는 0% 또는 기본 경고 상태로 안전하게 렌더링되고 예산 설정 유도 가이드를 표시해야 합니다.
- **당월 누적 지출액이 설정된 월 예산을 초과(100% 이상 소진)한 경우**:
  - 게이지 바가 우측 UI 경계를 뚫고 나가지 않도록 최대 100% 너비로 고정하되, 게이지 바의 색상을 강력한 경고 색상(예: 적색 계열)으로 표시하고 초과한 마이너스 예산 금액(예: -150,000원 초과)을 직관적으로 시각화합니다.
- **당월 등록된 가맹점의 수가 3개 미만인 경우**:
  - TOP 3 요약 카드는 오류 없이 존재하는 가맹점(예: 1개 혹은 2개)만 카드로 렌더링하고, 남은 빈 자리는 레이아웃을 유지하거나 빈 카드 상태로 자연스럽게 처리합니다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 사용자의 당월 결제 데이터를 기반으로 카테고리별 지출 총액 및 비율을 계산하여 분포도를 나타내는 원형(Pie/Donut) 차트를 제공해야 합니다.
- **FR-002**: 시스템은 기본 3개월로 조회 범위를 설정하되, 사용자가 필터 UI(3개월, 6개월, 12개월 등)를 통해 조회 개월 수를 선택하여 동적으로 데이터를 갱신할 수 있는 월별 지출 흐름 막대(Bar) 차트를 제공해야 합니다.
- **FR-003**: 시스템은 설정된 월 예산과 당월 누적 지출액을 비교하여 남은 예산과 소진 비율(%)을 실시간 계산하여 보존해야 합니다.
- **FR-004**: 예산 게이지 바는 소진율 수준에 따라 색상이 동적으로 변화하는 임계치 기반 시각화 로직을 반영해야 합니다. (예: 50% 미만 소진 시 녹색/안전, 50%~80% 소진 시 황색/주의, 80% 초과 소진 시 적색/경고)
- **FR-005**: 시스템은 이번 달 결제 건 중에서 당월 지출 총액 합산액이 가장 큰 가맹점 TOP 3를 선별하여 가맹점명 및 누적 지출 금액을 가시화하는 TOP 3 가맹점 요약 카드를 표시해야 합니다.
- **FR-006**: 가계부 데이터가 존재하지 않는 신규 유저 또는 극단적인 데이터 상태에서도 대시보드 레이아웃이 무너지지 않도록 기본 안내 및 폴백 UI를 적용해야 합니다.

### Key Entities

- **LedgerItem (결제 내역)**: 가계부에 기입되는 지출 개별 내역으로, 결제 금액, 가맹점 정보, 카테고리 정보 및 결제 일시를 속성으로 포함합니다.
- **MonthlyBudget (월별 예산)**: 각 사용자가 당월에 설정한 지출 목표 금액 정보로, 예산 총액과 설정 대상 연월을 속성으로 포함합니다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자가 대시보드 화면에 진입한 순간부터 차트 컴포넌트, 예산 게이지, TOP 3 가맹점 카드를 포함한 모든 시각화 요소가 화면에 나타나는 시간은 1.5초 이내여야 합니다.
- **SC-002**: 대시보드 내에서 예산 금액을 수정하거나 필터링을 변경했을 때, 화면의 페이지 새로고침(Reload) 없이 비동기로 0.5초 이내에 시각 그래프와 텍스트 지표가 실시간으로 동기화되어 갱신되어야 합니다.
- **SC-003**: 모바일 기기(너비 360px 이상)부터 데스크톱 해상도까지 다양한 뷰포트 영역에서 UI 레이아웃의 비틀림이나 글자 겹침이 0건이어야 하며, 100% 반응형 웹 브라우징 화면 비율을 준수해야 합니다.

## Assumptions

- 대시보드 데이터의 기본 조회 연월은 시스템 서버의 현재 타임존 기준 당월로 자동 매핑됩니다.
- 가계부 내역 중 카테고리 정보가 비어 있거나 올바르지 않은 경우, PostgreSQL DB 내 '미분류' 카테고리로 강제 강제 매핑 및 영속화하는 아키텍처 폴백 정책을 그대로 준수하여 분포 차트에 집계합니다.
- 가맹점 정보가 존재하지 않는(Null 또는 Blank) 결제 건은 요약 카드 집계 대상에서 자동으로 제외됩니다.
- 모든 지출 데이터와 예산 금액은 원화(KRW)를 기본 통화 단위로 가정하여 포맷팅합니다.
