# Feature Specification: frontend-dropzone-layout

**Feature Branch**: `007-frontend-dropzone-layout`

**Created**: 2026-06-02

**Status**: Draft

**Input**: User description: "프론트엔드 뷰(Vue 3) 애플리케이션 프로젝트 초기 구축 및 CSS 환경(Tailwind CSS) 세팅. 반응형 구조의 기본 영수증 업로드 드롭존(Dropzone) 레이아웃 퍼블리싱 완료."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 반응형 영수증 업로드 드롭존 레이아웃 (Priority: P1)

사용자는 웹 브라우저를 통해 영수증 업로드 페이지에 접속하고, 반응형 레이아웃 내에서 드래그 앤 드롭 또는 파일 선택기를 통해 영수증 파일을 손쉽게 드롭존 영역에 업로드할 수 있다.

**Why this priority**: 영수증 분석 자동화 서비스의 핵심 진입점으로, 사용자가 가장 먼저 영수증 파일을 올리기 위해 거쳐야 하는 필수 MVP 기능이다.

**Independent Test**: Vue 3 애플리케이션을 기동하여 드롭존 영역에 이미지 파일을 드롭하거나 클릭하여 파일을 선택했을 때, 드롭존 영역의 테두리가 활성화(하이라이트)되고 선택된 파일명이 프론트엔드 상태값에 정상 감지되는지 독립적으로 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 메인 화면에 있고 영수증 업로드 영역을 바라볼 때, **When** 화면 크기를 데스크톱(1024px 이상)에서 모바일(375px)로 줄여나갈 때, **Then** 드롭존 영역과 안내 문구 텍스트가 화면 크기에 맞춰 반응형으로 유연하게 재정렬된다.
2. **Given** 사용자가 로컬 기기에 영수증 이미지 파일(PNG)을 보유하고 있을 때, **When** 해당 파일을 브라우저의 드롭존 점선 영역 내부로 드래그하여 드롭할 때, **Then** 드롭존 테두리 스타일이 활성화(Highlight) 상태로 변경되며 파일이 브라우저 단에서 성공적으로 감지된다.

---

### User Story 2 - 업로드 영수증 파일 목록 피드백 및 개별 삭제 (Priority: P2)

사용자는 드롭존에 업로드한 영수증 파일들이 무엇인지 목록과 썸네일 미리보기를 통해 확인하고, 잘못 올린 파일은 목록에서 즉시 제거할 수 있다.

**Why this priority**: 사용자 실수로 잘못된 문서나 타인의 개인정보가 포함된 파일을 올렸을 경우, 서버 전송 전에 미리 확인하고 제거함으로써 UX 만족도와 데이터 정확도를 개선한다.

**Independent Test**: 복수의 파일을 연속으로 드롭존에 추가한 후 목록에 개별 항목(파일명, 용량, 미리보기 이미지)이 동적으로 생성되는지 확인하고, 각 항목의 '삭제' 버튼을 클릭했을 때 목록에서 실시간으로 제거되는지 검증한다.

**Acceptance Scenarios**:

1. **Given** 사용자가 복수의 이미지 파일을 드롭존에 드롭하여 추가했을 때, **When** 드롭존 하단에 감지된 파일 리스트가 렌더링되며, **Then** 각 파일별 파일명, 파일 용량 정보와 함께 이미지 썸네일 미리보기가 정상적으로 표시된다.
2. **Given** 사용자가 감지된 파일 목록에 2개의 영수증을 올려놓은 상태에서, **When** 특정 영수증의 '삭제' (X 아이콘 또는 버튼)를 클릭할 때, **Then** 선택한 영수증 파일만 목록에서 즉시 제거되고 나머지 파일은 그대로 유지된다.

### User Story 3 - 영수증 업로드 관련 에러 핸들링 및 형식 검증 (Priority: P3)

사용자는 허용되지 않은 파일 형식이나 너무 큰 파일을 업로드했을 때, 무엇이 문제인지 명확한 경고 피드백을 받아 올바른 파일을 다시 올릴 수 있다.

**Why this priority**: 시스템 리소스 낭비를 사전에 방지하고, 올바르지 않은 입력에 대해 사용자에게 직관적이고 친절한 실시간 피드백 가이드를 프론트엔드 단에서 제공한다.

**Independent Test**: 10MB가 넘는 초고용량 이미지 파일이나 `.txt` 텍스트 파일을 업로드해보고, 에러 경고 메시지 또는 토스트 알림이 반응형 레이아웃 내에 깨짐 없이 적절하게 노출되는지 검증한다.

**Acceptance Scenarios**:

1. **Given** 사용자가 업로드할 파일로 지원하지 않는 확장자(`.exe`, `.txt`)를 선택하여 올렸을 때, **When** 파일 감지가 수행되는 즉시, **Then** "지원하지 않는 파일 형식입니다. 이미지(JPG, PNG) 또는 PDF 파일만 업로드할 수 있습니다."라는 직관적인 에러 피드백이 표시된다.
2. **Given** 사용자가 50MB 용량의 대용량 이미지 파일을 업로드 영역에 투하했을 때, **When** 유효성 검사가 작동할 때, **Then** "최대 파일 용량(10MB)을 초과하는 파일은 업로드할 수 없습니다."라는 경고 피드백이 노출되며 목록 추가를 차단한다.

### Edge Cases

- 네트워크 단절 상태(오프라인 모드)에서 파일 업로드 시도 시, 네트워크 연결이 필요함을 알리는 반응형 에러 배너를 렌더링한다.
- 빈 파일(0 bytes)을 업로드할 경우, "유효하지 않은 빈 파일입니다"라는 경고 메시지를 표시하고 처리를 중단한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 사용자가 영수증 파일을 드래그 앤 드롭하여 업로드할 수 있는 직관적인 반응형 드롭존 컴포넌트를 UI 상에 제공해야 한다.
- **FR-002**: 드롭존은 파일 드래그 시 테두리 하이라이트 등 시각적 상호작용 피드백을 사용자에게 명확히 전달해야 한다. (성능 보호를 위해 테두리 애니메이션 효과는 GPU 하드웨어 가속 속성인 `will-change: transform`을 기반으로 설계하며, 모바일 배터리 세이빙 모드 등을 대비하여 프레임 드랍이 없는 정적 하이라이트 CSS 구조를 병행 구축한다.)
- **FR-003**: 시스템은 업로드된 파일의 형식(MIME Type) 및 파일 용량(Size)을 프론트엔드 단에서 1차 검증(Validate)해야 한다.
- **FR-004**: 드롭존에 업로드 가능한 파일의 최대 수량은 단일 업로드(최대 1개)로 제한하며, 새로운 파일 업로드 시 기존에 감지된 파일을 덮어쓰고 최신 파일로 대체하도록 구현해야 한다.
- **FR-005**: 시스템은 드롭존 하단에 업로드된 영수증의 미리보기(썸네일) 목록 및 개별 파일 삭제 기능을 UI 상에 제공해야 한다.
- **FR-006**: 드롭존 영역 및 전체 메인 레이아웃은 데스크톱, 태블릿, 모바일 해상도(375px ~ 1920px)를 완벽하게 지원하는 반응형 구조로 설계되어야 한다.
- **FR-007**: 전체 프론트엔드 스타일 및 테마는 모던 슬레이트 다크 모드를 디폴트로 하며, 핀테크 대시보드 느낌의 짙은 slate 계열 백그라운드에 세련된 indigo/violet 포인트를 부여하는 Tailwind CSS 환경을 세팅 및 구축해야 한다.

### Key Entities *(include if feature involves data)*

- **ReceiptFile (영수증 파일 엔티티)**: 사용자가 업로드한 개별 영수증 문서 정보를 추상화한 객체.
  - `id`: 파일 고유 식별자 (UUIDv7 호환 포맷 권장)
  - `name`: 원본 파일명 (예: `receipt_20260602.png`)
  - `size`: 파일 크기 (바이트 단위)
  - `type`: 파일 MIME 타입 (예: `image/png`, `application/pdf`)
  - `previewUrl`: 브라우저 내 미리보기를 위한 임시 Object URL
  - `createdAt`: 업로드 감지 시각

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 모바일(375px)부터 울트라 와이드 데스크톱(1920px)까지 화면 너비를 전환하더라도 레이아웃의 깨짐이나 수평 스크롤바가 발생하지 않고 뷰포트에 안전하게 반응형 배치된다.
- **SC-002**: 사용자가 파일을 드롭존에 올리거나 선택을 완료한 시점으로부터 0.5초 이내에 썸네일 및 파일 상세 정보 목록이 지연 없이 즉각 렌더링된다.
- **SC-003**: 비정상 파일(허용 불가 형식, 10MB 초과 대용량) 업로드 감지 시, 0.3초 이내에 에러 토스트 또는 드롭존 안내 레이블을 통해 사용자에게 에러 상태를 시각화하여 전달한다.

## Assumptions

- 백엔드 서버(Django) API 및 파일 보관용 스토리지 연동 처리는 이번 초기 퍼블리싱 스프린트 범위에서 제외되며, 프론트엔드 단의 컴포넌트 세팅 및 상태값 검증에 온전히 집중한다.
- 최종 사용자는 모던 웹 브라우저(Chrome, Safari, Firefox, Edge 최신 버전) 환경을 통해 본 서비스에 액세스한다.
- 10MB 이하의 이미지 파일(JPEG, PNG) 및 PDF 파일 포맷만을 유효한 영수증 규격으로 인정한다.
- 별도의 테마 가이드가 미정인 상태에서는 Tailwind CSS의 기본 slate/indigo 계열 팔레트를 활용하여 고도로 세련되고 모던한 다크/라이트 하이브리드 스타일을 초기 가적용한다.
