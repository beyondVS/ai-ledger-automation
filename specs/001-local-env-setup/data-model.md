# Data Model: 로컬 PostgreSQL v18+ 인프라 명세

본 1일차 개발 계획(001-local-env-setup)은 데이터 비즈니스 모델(가계부, 품목 등) 수립 이전의 **데이터베이스 시스템 인프라 기초 사양**을 수립합니다. 이에 따라 RDBMS 컨테이너의 시스템 인스턴스, 영속 볼륨, 그리고 주입 환경 변수를 주요 엔티티로 구성합니다.

---

## 1. RDBMS 시스템 엔티티 명세

### [Entity 1] `ai_ledger` (RDBMS Database)
* **설명**: 금융 거래 분석 정보 및 자동화 가계부 원장을 관리하기 위한 PostgreSQL RDBMS 물리 데이터베이스 인스턴스입니다.
* **시스템 인코딩**: `UTF-8` (한글 세금계산서/영수증 텍스트 깨짐 원천 방지)
* **엔진 시간대 (TimeZone)**: `Asia/Seoul` (한국 표준시 기준 거래 일자 타임스탬프 무결성 보장)
* **외부 매핑 포트**: `5432` (로컬 호스트의 5432 포트가 기점유되어 충돌 시 `.env.local`을 통해 유연한 변경 허용)

### [Entity 2] `postgres_data` (Docker Named Volume)
* **설명**: 컨테이너 폐기 및 재부팅 시에도 로컬 개발 데이터 유실을 100% 방지하기 위해 도커 엔진이 격리 관리하는 영속적 볼륨입니다.
* **컨테이너 내부 바인딩 마운트 경로**: `/var/lib/postgresql`
* **드라이버**: `local` (Docker Default local driver)

### [Entity 3] `.env.local` (보안 환경 변수 세트)
* **설명**: 소스 코드 노출 및 커밋 유출을 완벽히 격리하기 위해 로컬 호스트에 수동 주입하는 시스템 자격 증명 엔티티 세트입니다.
* **주요 속성**:
  * `POSTGRES_DB`: 초기 생성할 타깃 데이터베이스 명 (기본값: `ai_ledger`)
  * `POSTGRES_USER`: 서버 관리자 계정 ID (기본값: `postgres`)
  * `POSTGRES_PASSWORD`: 데이터베이스 슈퍼유저 비밀번호 (보안 유지를 위해 공백 불가 및 강력한 암호 권장)
  * `POSTGRES_PORT`: 호스트에 바인딩할 외부 접근 포트 (기본값: `5432`)

---

## 2. 유효성 검사 및 정합성 제약 규칙

1. **인코딩 정합성**: 컨테이너 초기 기동 스크립트 실행 시, 문자셋이 `UTF-8` 외의 다른 인코딩(예: LATIN1 등)으로 초기화되지 않도록 명시적인 Docker Compose 또는 Docker Run 옵션을 부여합니다.
2. **시간대 정합성**: 컨테이너 환경 변수로 `TZ=Asia/Seoul` 및 PostgreSQL 구성 파라미터로 `timezone='Asia/Seoul'`을 주입하여 가계부 데이터의 9시간 시차 밀림 오류를 방지합니다.
3. **볼륨 바인딩 검증**: 컨테이너 구동 성공 후, Docker inspect를 통해 네임드 볼륨 `postgres_data`가 컨테이너 쓰기 경로에 정상적으로 바인딩되었는지 검증해야 합니다.
