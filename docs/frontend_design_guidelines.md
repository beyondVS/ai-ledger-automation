# Frontend Design & UX Guidelines

본 문서는 **Smart Ledger** 프로젝트의 프론트엔드 클라이언트(Vue.js 3 + Tailwind CSS) 개발 시 지켜야 하는 **디자인 시스템 및 UX/UI 일관성 수립을 위한 핵심 가이드라인**입니다. 향후 모든 신규 화면 개발 및 컴포넌트 리팩토링 시 아래 명시된 규칙을 일관성 있게 준수하십시오.

---

## 🧭 1. 네비게이션 및 레이아웃 규칙 (Layout & Navigation)

모든 독립적인 단독 페이지(예: 대시보드, 템플릿 관리, 환경 설정 등)는 사용자가 다른 서비스 기능 탭으로 막힘없이 자유롭게 넘나들 수 있도록 **동일한 헤더 내비게이션 바**를 필수로 부착해야 합니다.

*   **상단 네비바 부착 규정**:
    *   모든 단독 라우트 페이지 컴포넌트의 최상단에는 `<NavBar />` 컴포넌트가 필수로 임포트 및 마운트되어야 합니다.
    *   네비바 하위에 카드나 컨테이너가 오는 경우, 시각적인 답답함을 방지하기 위해 `mt-4` ~ `mt-6` 정도의 수직 여백(Margin)을 두어 공백 감각을 확보합니다.
*   **반응형 레이아웃**:
    *   화면 컨테이너의 최대 폭은 데스크톱 크기에 맞춰 `max-w-lg md:max-w-4xl lg:max-w-5xl` 규격을 일관되게 차용합니다.
    *   모바일 환경에서는 양쪽 여백 `px-4`를 부여하여 화면 끝에 콘텐츠가 달라붙지 않게 방어합니다.

## 🎨 2. 컬러 시스템 및 다크모드 (Color System & Dark Mode)

Smart Ledger는 세련된 HSL 기반의 다크 모드를 기본(Default) 테마로 하며, 다크/라이트모드 하이브리드 전환 시 눈의 피로를 최소화하는 색상 대비를 유지합니다.

### 2.1 배경 및 테두리 색상
| 역할 | 라이트 모드 (Light Mode) | 다크 모드 (Dark Mode) | 설명 |
| :--- | :--- | :--- | :--- |
| **기본 배경** | `bg-slate-50` | `bg-slate-950` | 전체 서비스 스크린 배경 |
| **카드 배경** | `bg-white` | `bg-slate-900` | 컨텐츠 영역 카드 배경 |
| **기본 테두리** | `border-slate-200/60` | `border-slate-800/80` | 미세한 대비를 주는 선 |
| **기본 텍스트** | `text-slate-900` | `text-slate-100` | 가독성이 높은 본문 서체 |
| **보조 설명** | `text-slate-500` | `text-slate-400` | 부연 설명을 위한 서체 |

### 2.2 브랜드 포인트 컬러 (Gradients)
*   **메인 그라데이션**: `from-indigo-600 to-purple-600` (라이트) / `from-indigo-500 to-purple-500` (다크)
*   **포인트 그린**: `from-emerald-500 via-teal-500 to-indigo-500`
*   브랜드 색상(Red, Blue) 사용 시 원색 `#FF0000` 등 브라우저 기본값의 사용은 **엄격히 금지**하며, 반드시 Tailwind의 HSL 조율 톤(`rose-500`, `indigo-500` 등)만 사용합니다.

## 🔲 3. 컴포넌트 및 카드 규격 (Components & Cards)

*   **모서리 둥글기 (Rounding)**:
    *   가장 강조되어 시선을 끄는 대형 설정/입력 카드는 `rounded-3xl` (24px)을 적용합니다.
    *   일반 서브 컴포넌트 패널(캘린더 그리드, 상세 검색 패널 등)은 `rounded-2xl` (16px)을 적용합니다.
    *   작은 입력창(Input, Select) 및 상세 버튼들은 `rounded-xl` (12px)을 일관되게 사용합니다.
*   **그림자 (Shadow)**:
    *   가장 우선순위가 높은 조작 팝업/모달은 `shadow-2xl`을 사용하여 확실한 Z축 입체감을 부여합니다.
    *   메인 영역 카드는 `shadow-xl` 또는 `shadow-lg`를 가미해 미려하게 띄웁니다.

## ⏳ 4. UX 피드백 및 마이크로 애니메이션 (Micro-animations)

*   **상태 지시자 (State Indicators)**:
    *   사용자가 저장을 누르거나 데이터를 불러올 때, 무반응 상태로 방치하지 않고 회전하는 스피너(`animate-spin`) 혹은 맥박 형태의 로딩 인디케이터(`animate-pulse`)를 필수로 바인딩합니다.
*   **부드러운 호버 트랜지션 (Transitions)**:
    *   클릭 가능한 카드나 일자 격자 등에는 `hover:scale-[1.02] active:scale-[0.98] transition-all duration-200` 규격을 기본 적용하여 핀테크 감성의 쫀득하고 매끄러운 반응성을 선사합니다.
*   **모달/피드백 애니메이션**:
    *   성공/실패 토스트 메시지나 팝업 모달이 켜질 때는 단순 표시가 아닌 페이드인(`animate-fade-in` 또는 `<transition name="fade">`) 애니메이션을 통하여 사용자 시각 인지 과정을 부드럽게 돕습니다.
